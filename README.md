# Login & Register Page

A simple **Persian login and registration page** created as a practice project.

## 📌 About the Project

This project was created to practice **HTML and CSS** and improve frontend development skills.

It includes two Persian (RTL) pages:

* 🔐 **Login Page** — User login page
* 📝 **Register Page** — User registration page

The user interfaces were first designed in **Figma** and then implemented using **HTML and CSS**.

## 🎨 Figma Designs

The designs for both pages were created in Figma:

* [Login Page – Figma](https://www.figma.com/site/5pqHQvdkhhPz1ctMG0nzxD/login-page-figma?t=thXhHkEJrvzzblSz-1)
* [Register Page – Figma](https://www.figma.com/site/bdtKtCJ4Q47y7KQxOC1cM2/register-page?t=thXhHkEJrvzzblSz-1)

## 🛠️ Technologies

* HTML5
* CSS3
* Figma

## ✨ Features

* Persian (RTL) user interface
* Login form
* Registration form
* Email / mobile number input
* Password input
* Navigation between login and registration pages
* Styled form inputs and buttons
* Hover and focus states
